## 使用原则

- `prototypes/` 只作为交互参考，不作为真实接口证据。
- Django 沙箱只模拟当前已知契约，不代表完整省平台。
- 默认运行模式是 `DRY_RUN`；`LIVE` 在真实授权和测试车辆联调前固定阻断。
- 正式规则和固定音频必须先由业务方确认。
- 无规则、规则冲突、字段不足、动作失败或结果不确定时统一转人工。
- 不提交真实账号、Cookie、Token、车牌、司机、位置、抓包、视频和证据 URL。
- 监控处置、规则配置、规则审核和敏感导出必须职责分离。
- 文本和语音是独立响应渠道，均使用已审核固定模板。
- 完整 JSON 属于敏感证据，不作为普通值班导出。
