## 3. 真实报警字段

实时报警、技术检测、查询和详情已经确认存在以下字段族：

- 身份：`id`、`alarmId`、`alarmTypeId`、`alarmName`、`alarmTime`。
- 车辆：`carId`、`certId`、`certColor`、`vehicleTypeName`、`vehicleModelType`。
- 司机：`driverName`、`driverNumber`、`contactInformation`。
- 企业：`companyId`、`companyName`、`groupId`、`groupName`。
- 位置：`location`、`posDesc`、`marsLat`、`marsLon`、`lat`、`lon`、`locationSpeed`、`pulseSpeed`。
- 平台流程：`alarmStatus`、`alarmCompleteStatus`、`dealFlag`、`dispositionFlag`、`ignoreStatus`、`verificationStatus`、`evidenceAuditStatus`、`appealResult`、`positiveReportingFLag`。
- 证据：`images`、`videos`、`processes`、`posTrackDtoList`。

插件使用 `id` 作为报警记录 ID，`alarmTypeId`/`alarmId` 作为类型标识；文字地址缺失时使用火星坐标形成位置兜底。密码、Cookie、Authorization、Token、手机号和证件类字段不进入普通记录或导出。

## 4. 已修正的契约问题

1. `alarmQueryList` 真实出现于报警申诉、报警核验和历史记录页面，不能再标记为预警列表；已改为 `HISTORY` 并强制只记录。
2. 2026-07-20 真实页面复核确认：预报警页面路由为 `#/alarm-center/pr-alarm-recorde`，复用 `alarmQueryList`；必须结合路由标记为 `PREWARNING`。平台负责预报警阈值以及向正式报警的升级判定。`alarmPreProcessingInfo` 是报警预处理/待处理正式报警明细，标记为 `PENDING`。
3. 同一事件每次轮询追加全部抓取 ID 会导致文件无界增长。来源现按接口聚合首次/最近抓取和出现次数，只保留最近 20 个抓取引用。
4. 历史事件和台账快照完成压缩：事件文件从约 412MB 降至约 203KB；原始加密抓取、动作记录和审计记录未删除。
