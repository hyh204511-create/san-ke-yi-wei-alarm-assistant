# 三客一危值班助手：数据展示、日报月报与导出规划

版本：`1.0`  
形成日期：`2026-07-19`

## 1. 产品边界

数据展示与导出建设为独立“数据与报表中心”，与浏览器插件的实时报警操作分开。插件只展示当前工作所需状态和待办；正式日报、月报、企业对比和历史导出在报表中心完成。

## 2. 数据主题

| 主题 | 主要数据 |
| --- | --- |
| 报警事实 | 报警 ID、类型、时间、车辆、企业、位置、速度、平台状态 |
| 处置过程 | 规则、处理策略、文本/语音尝试、人工任务、开始结束时间 |
| 处置结果 | 成功、失败、未知、转人工、完成、复核 |
| 组织企业 | 集团、分公司、企业、车辆归属和历史归属快照 |
| 数据质量 | 缺字段、冲突、接口错误、页面变化、同步延迟 |
| 审计 | 规则、处置、导出和敏感访问 |

## 3. 页面结构

1. 运行概览：当前报警、待人工、超时、文本/语音通道状态。
2. 企业驾驶舱：授权企业的报警、处置和趋势。
3. 处置台账：可查询的事件、动作、人工任务和最终结果。
4. 日报中心：按日期和企业生成、查看和下载。
5. 月报中心：按月份、集团/分公司/企业生成和归档。
6. 导出任务：查看生成进度、失败原因、下载记录和过期时间。
7. 数据质量：缺字段、冲突、接口变化和异常来源。

## 4. 日报口径建议

- 统计日期和数据截止时间。
- 组织、企业和车辆数量。
- 报警总量及类型分布。
- 自动文本计划数、成功数、失败数和成功率。
- 自动语音计划数、成功数、失败数和成功率。
- 文本升级语音次数。
- 自动转人工数量、人工完成量和未完成量。
- 平均首次响应时间、平均处置时长和超时量。
- 高频报警车辆和主要失败原因。
- 缺字段、冲突和接口异常数量。

## 5. 月报口径建议

- 月份、统计范围、数据截止时间和报表模板版本。
- 集团、分公司、企业和车辆规模。
- 报警总量、类型分布、日趋势和环比。
- 处置完成率、自动响应率、人工接管率和超时率。
- 文本、语音和组合策略的成功率。
- 重复报警车辆、高风险事件和未闭环事件。
- 企业间对比和排名；是否开放由权限决定。
- 数据完整率、冲突率和接口异常。
- 规则版本变更对统计口径的影响说明。

## 6. 报表生成流程

```mermaid
flowchart LR
    A["报表员选择企业、周期和模板"] --> B["权限与企业范围校验"]
    B --> C["冻结查询参数和数据截止时间"]
    C --> D["聚合报警、处置、渠道和质量数据"]
    D --> E["生成 ReportSnapshot"]
    E --> F["生成 XLSX/PDF"]
    F --> G["记录文件哈希、生成者和下载期限"]
    G --> H["授权下载与归档"]
```

报表必须可复现：相同快照、相同模板版本应得到相同结果；后续数据变化不能修改已经归档的报表。

默认使用北京时间并按报警发生时间归属统计周期。迟到数据、平台补数或口径修正不能覆盖已发布快照，必须生成带更正原因和差异说明的新版本；车辆和企业维度使用事件发生时的归属快照。

## 7. 导出类型

| 类型 | 典型格式 | 数据范围 | 权限 |
| --- | --- | --- | --- |
| 汇总报表 | XLSX/PDF | 聚合指标 | 报表员及授权管理人员 |
| 脱敏明细 | XLSX/CSV | 车牌/司机/位置掩码 | 具有明细权限的报表员 |
| 内部处置台账 | XLSX | 授权企业业务明细 | 处置复核员/报表员 |
| 敏感证据包 | 加密 JSON/受控压缩包 | 完整明细和证据引用 | 专门权限或审批 |

## 8. ExportJob

每次导出记录：

```text
exportJobId
requestedBy / requestedRole
organizationScope / enterpriseScope
reportType / templateVersion
filters / period / dataCutoffAt
sensitivityLevel / maskingPolicy
purpose / approvalId
status / failureReason
fileName / fileHash / expiresAt
createdAt / completedAt / downloadedAt
```

状态：

```text
CREATED → AUTHORIZING → GENERATING → READY → DOWNLOADED / EXPIRED
                         ↘ FAILED
```

## 9. 完整 JSON 管控

完整 JSON 不在普通报表页面直接提供。确需技术排障、审计或证据核查时，使用“敏感证据包”流程：

1. 选择明确事件和最小时间范围。
2. 展示将包含的敏感字段。
3. 填写用途和接收范围。
4. 校验专门权限或审批。
5. 再次执行凭证脱敏，禁止包含 Cookie、Token 和密码。
6. 生成文件哈希、过期时间和下载审计。
7. 文件进入受控目录或加密存储。

## 10. 待业务确认

- 日报、月报正式模板。
- 月报是否优先于日报。
- 集团、分公司、企业权威关系表。
- 跨企业排名是否允许及展示范围。
- 车辆数、报警数、处置率、在线率等指标口径。
- 报表生成时间、数据截止时间和补数规则。
- 敏感证据包审批和保留期限。
