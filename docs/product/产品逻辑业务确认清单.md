# 三客一危值班助手：产品逻辑业务确认清单

> 2026-07-19 更新：已基于全量文档和最新需求形成 [无人值守产品逻辑规划 V3](三客一危无人值守报警处置系统-产品逻辑规划-v3.md) 与 [无人值守规则与动作编排 V3](../engineering/无人值守报警规则与动作编排设计-v3.md)。V3 已给出多浏览器中心协同、单渠道优先、失败转人工、短信升级和72小时无人值守验收的推荐默认值。本清单后续只用于取得会话续期、真实动作、报警矩阵、短信、报表和安全制度的正式签字。

用途：在继续大规模编码前，由项目负责人、业务方、安全/数据负责人逐项确认产品口径

## 1. 已确立的产品基线

以下原则不应再按早期单人插件思路回退：

- 产品由监控处置、规则治理、数据与报表、审计与安全四个业务域组成。
- 监控操作、规则配置和规则审核职责分离；配置人不能审核本人版本。
- 文本与语音是独立响应渠道，均使用已审核、已发布的固定模板。
- 自动失败、结果未知、关键字段缺失和规则冲突统一产生人工待办。
- 企业日报、月报、历史查询和正式导出在独立数据与报表中心完成。
- 完整 JSON 属于高敏证据包，不是普通值班员日常导出。
- 省平台事实、助手判断和人工记录分层保存，不能静默互相覆盖。
- 当前浏览器插件是技术 MVP，不等于最终多角色业务系统。

## 2. 必须确认的业务决策

| 编号 | 决策项 | 需要业务方给出的明确答案 | 未确认时的默认安全行为 | 阻塞阶段 |
| --- | --- | --- | --- | --- |
| R01 | 角色人员 | 各角色正式名称、人员名单、替岗与交接方式 | 不开通生产权限 | 多用户上线 |
| R02 | 规则职责 | 配置人、审核人、发布人是否三岗或两岗 | 配置人不得审核/发布本人版本 | 规则中心 |
| R03 | 高风险复核 | 哪些报警和结果必须班组复核 | 转人工并等待复核 | 处置闭环 |
| I01 | 身份绑定 | 助手实名用户如何绑定省平台账号/班次 | 身份不明时禁止真实动作和敏感导出 | 真实联调 |
| E01 | 企业关系 | 集团、分公司、企业、车辆的权威关系及历史变更来源 | 不做跨企业汇总 | 报表中心 |
| A01 | 报警主键 | 真实报警 ID、重复报警和合并口径 | 弱身份事件不自动执行 | 数据归并 |
| A02 | 完成标准 | 一般处置、高风险处置、复核完成和重开条件 | 不能明确完成时保持人工待办 | 处置闭环 |
| C01 | 文本接收对象 | 文本发往车载终端、司机、企业联系人或站内对象 | 不执行真实文本 | 文本适配 |
| C02 | 文本成功判据 | 平台受理、终端送达、已读分别如何定义 | 无明确回执记 `UNKNOWN` 并转人工 | 文本适配 |
| C03 | 语音成功判据 | 连接、发送完成、播放完成、司机确认的口径 | 无明确回执记 `UNKNOWN`，不自动重播 | 语音适配 |
| C04 | 渠道编排 | 各报警用文本、语音、顺序、并行还是兜底 | 默认人工，不同时自动触发双渠道 | 规则发布 |
| T01 | 模板治理 | 文本/音频审核部门、有效期、撤回和紧急停用流程 | 未发布模板不可执行 | 规则中心 |
| P01 | 真实动作范围 | 授权账号、测试车辆、企业范围和联调时段 | 保持演练模式 | 真实联调 |
| D01 | 日报口径 | 截止时间、企业范围、指标定义、补数与接收人 | 只生成未发布草稿 | 日报上线 |
| D02 | 月报口径 | 模板、指标、环比、排名、发布时间和归档期限 | 不生成正式月报 | 月报上线 |
| D03 | 企业排名 | 是否允许集团/企业横向排名及可见范围 | 默认不展示跨企业排名 | 报表中心 |
| S01 | 敏感级别 | 车牌、司机、位置、视频、备注的页面与导出权限 | 按高敏处理 | 数据安全 |
| S02 | 证据包 | 申请人、审批人、用途、加密、保留期和删除方式 | 禁止生成完整证据包 | 敏感导出 |
| S03 | 数据保留 | Capture、事件、动作、报表、视频图片的保留期限 | 采用最短必要期限并禁止外发 | 生产上线 |

## 5. 进入下一阶段的门槛

### 可继续做技术底座

在业务问题未全部确认前，仍可继续完善只读采集、事件归并、来源追踪、沙箱异常场景和演练状态机，因为这些能力不替业务方决定处置口径。

### 不应提前进入生产实现

以下工作必须等对应决策确认：

- 未确认文本接收对象与成功判据前，不接生产文本下发。
- 未确认语音链路、模板和测试车辆前，不接生产对讲。
- 未完成配置/审核职责分离前，不发布自动规则。
- 未取得企业权威关系与统计口径前，不交付正式日报/月报。
- 未确认专门权限、用途和保留制度前，不提供完整 JSON/证据包下载。
